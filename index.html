Häufige Fragen

Können Sie meine bestehende Website übernehmen?

Ja. Ihre Website wird modern neu aufgebaut, Texte und Bilder werden übernommen. Ihre Domain bleibt auf Ihren Namen, nur die Einstellung, wohin sie zeigt, wird angepasst. Ihre E-Mail-Adressen funktionieren dabei unverändert weiter.

Mit welcher Technik wird die Website gebaut?

Jede Website wird individuell programmiert, ohne Baukasten. Sie lädt schnell, ist sicher und kostet Sie kein Baukasten-Abo.

Welche laufenden Kosten kommen dazu?

Damit Ihre Website online ist, braucht sie ein Hosting. Hosting und Betreuung kosten CHF 450 pro Jahr, inklusive kleiner Änderungen. Dazu kommt die Domain für rund CHF 15 pro Jahr. Haben Sie bereits einen eigenen Hosting-Anbieter, erhalten Sie die fertigen Dateien; spätere Änderungen werden dann nach Aufwand verrechnet.

Kann ich später etwas ändern lassen?

Ja. Schicken Sie einfach eine E-Mail. Kleine Änderungen wie neue Fotos, Texte oder der Status einer Wohnung sind im Hosting-Paket enthalten, grössere Anpassungen werden Ihnen vorab offeriert.

Wie lange dauert es, bis die Website online ist?

Meist zwei bis vier Wochen, je nachdem, wie schnell Texte und Fotos bereit sind.
